MultiSpeaker 1.0.0 —— 多扬声器同步播放器
================================================

一、它能做什么
  把同一个立体声音频同时送到电脑上的任意多个扬声器 / 声卡 / HDMI / 蓝牙设备，
  每台设备都保留完整的左(L)、右(R)声道，绝不会混成单声道。
  所有设备由同一个主时钟对齐，长时间播放也不会逐渐错位。

二、快速上手
  1. 左侧「输出设备」里勾选要同时发声的扬声器（可多选；播放过程中勾选会立即加入）。
  2. 点右上角「选择文件」，或把音频文件 / 文件夹直接拖进窗口。
  3. 点播放（或按空格键）。所有勾选的设备会同时开始播放。
  4. 「声道测试」会依次播放 左声道 → 右声道 → 双声道，
     用来确认每台设备都是真正的立体声输出。

三、每台设备的控制
  · 音量滑杆：单独调节这台设备的音量，不影响其他设备。
  · M：静音这台设备。
  · S：独奏，只听这一台（用来确认哪个音箱对应列表里的哪个设备）。
  · 延迟补偿(ms)：给这台设备增加延迟，用于对齐蓝牙音箱等本身延迟较大的设备。
    正值 = 这台设备比其他设备更晚出声。

四、支持的格式
  MP3 / FLAC / WAV / M4A(AAC) / OGG / OPUS / WMA / AIFF / APE / MP4 / MKV 等。
  内部使用 FFmpeg 解码，44.1k / 48k / 96k 等任意采样率都会自动转换到设备采样率。

五、小提示
  · 5.1 / 7.1 多声道设备默认把 L/R 分配到前置、后置各一对扬声器；
    可在右上角「设置」里改为仅使用前置声道。
  · 设置会自动保存，下次打开时恢复上次勾选的设备、音量与播放列表。
  · 支持 Windows 10 / 11 64 位。

六、系统音频（让所有程序的声音都走组合输出）
  安装时已同时注册虚拟声卡，Windows「播放设备」里会出现：
      「MultiSpeaker 组合输出 (VB-Audio Virtual Cable)」
  1. Windows 设置 → 系统 → 声音 → 输出：选择「MultiSpeaker 组合输出」。
  2. 回到 MultiSpeaker，勾选要同时发声的扬声器，
     点顶部「系统音频」卡片上的「开始转发」。
  3. 此后所有程序（浏览器、音乐软件、游戏……）的声音都会同步出现在这些扬声器上。
  · 停止：点「停止转发」，并把 Windows 默认输出切回原来的设备。
  · 转发链路有约 80 ms 缓冲；各扬声器可用「延迟补偿」对齐。
  · 若重装系统或换电脑，需重新安装虚拟声卡（VB-CABLE / VoiceMeeter）。

七、启动与托盘
  · 右上角「设置」里可以勾选「开机自动启动」：
    登录 Windows 后软件会自动在托盘运行（不弹窗）。
  · 同一处还可以选择点击窗口关闭按钮时的行为：
      - 最小化到托盘（音乐继续播放，推荐）
      - 直接退出程序
  · 托盘图标操作：
      - 单击：打开主界面
      - 右键：菜单里可选「打开主界面」或「退出 MultiSpeaker」

八、卸载
  开始菜单 → MultiSpeaker → 卸载 MultiSpeaker，
  或：Windows 设置 → 应用 → 已安装的应用 → MultiSpeaker → 卸载。
