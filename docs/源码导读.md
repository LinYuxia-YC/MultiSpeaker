# 源码导读

> MultiSpeaker 1.1.2 · Windows 10/11 · Python 3.10 / PySide6

这份文档帮助你在阅读源码前建立整体印象：数据怎么流动、同步是怎么做到的、每个文件负责什么。

## 1. 目录结构

```text

app/
```

## 2. 两条数据通路

### 文件播放

```text
mp3/flac/...  →  decode_track()  →  DecodedTrack(data=(n,ch), rate, layout)
                                        │
                          engine.set_track()  （按源声道刷新声道模式）
                                        │
                          engine.start(devices)
                                        │
        每个设备一个 _DeviceWorker：按设备采样率重采样 + 独立输出流
```

### 系统音频（虚拟声卡）

```text
其它程序 → Windows 默认输出 = MultiSpeaker 组合输出（VB-CABLE）
        → CABLE Output  →  LiveSource（环形缓冲）
        →  engine.start_live(devices)  →  同一套 _DeviceWorker
```

采集端固定 2 声道，因此系统音频在「自动」声道模式下按立体声处理。

## 3. 同步是怎么做到的

所有设备共用一条“可听时间轴” `t0`。设备 *i* 在墙钟时间 *t* 读取源位置：

```text
pos_i(t) = (t + latency_i − t0) · rate_i
```

- `latency_i`：该设备上报的输出延迟（`stream.latency`），**按自身延迟提前读取**，
  这样同一采样会在所有扬声器上同时响起。
- 每个回调用 `perf_counter()` 与目标位置比较，误差超过约 1.5 ms 时，
  用 ±0.4% 的速率微调（`ratio`）把读取位置缓慢拉回；偏差过大（拖动进度）则直接重定位。
- 读取位置是浮点数，用 Catmull-Rom 插值保证连续；`ratio=1` 时走整数快路径，几乎零开销。

启动时 `start()` 先打开所有流、读取真实延迟，再把 `t0` 设为“当前时间 + 最大延迟 + 余量”，
因此第一帧会在同一时刻到达所有设备。

暂停采用“淡出 → 冻结时钟 → 恢复时平移 `t0`”，输出流不断开，恢复无爆音。

## 4. 声道映射

`chmap.build_matrix(src_names, dev_channels, channel_mode)` 返回一个
`(源声道数 × 设备声道数)` 的增益矩阵，回调里用一次矩阵乘法完成映射：

| 情况 | 规则 |
|---|---|
| 单声道源 | 铺满所有声道（LFE 除外） |
| 双声道源 → 双声道设备 | 直通（恒等矩阵） |
| 双声道源 → 5.1/7.1 设备 | 前置 L/R；中置 0.25·(L+R)；后置 0.707·L/R（`front` 模式不下发后置） |
| 5.1 源 → 5.1/7.1 设备 | 同名声道直通 |
| 5.1/7.1 源 → 双声道设备 | FL/FR 各归左右，FC 与环绕按 0.707 折叠，LFE 丢弃 |

「自动」声道模式只在**单声道源**时合并；双声道以上一律按源布局还原。

## 5. 线程模型

- **GUI 线程**：Qt 事件循环、30 Hz 定时器刷新进度/电平/系统音量回显。
- **PortAudio 回调线程**（每个设备一个）：只做数学运算与内存拷贝，不碰 UI、不加锁。
- **解码线程**（`Loader`）：文件解码在后台进行，完成后通过信号回到 GUI 线程。
- **采集线程**：`LiveSource` 的回调把数据写入环形缓冲。

引擎对共享状态的修改（增删设备、seek）都持有 `self._lock`；回调只读，因此不会与 GUI 互锁。

## 6. 音量与系统集成

- 设备卡片的音量滑杆优先调用 `sysvol.SystemVolume`（`IAudioEndpointVolume`），
  直接修改 Windows 端点音量，并每秒回读一次，系统侧的改动会反映到界面。
- 若某个端点匹配不到，自动退回为软件增益（`engine.set_gain`）。
- 静音同理：优先端点静音，失败则软件静音。

## 7. 配置与持久化

`QSettings("MultiSpeaker", "MultiSpeaker")` 写入注册表 `HKCU\Software\MultiSpeaker`：

| 键 | 含义 |
|---|---|
| `selected` | 勾选的设备 key 列表 |
| `gain/<key>` / `delay/<key>` / `mute/<key>` | 设备级参数（软件回退用） |
| `mono_mode` | `auto` / `mono` / `stereo` |
| `channel_mode` | 多声道设备分配方式 |
| `close_action` | 关闭窗口行为：`tray` / `exit` |
| `playlist` / `geometry` / `master_volume` / `repeat` | 播放列表与窗口状态 |

开机自启写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。

## 8. 构建

```powershell
pip install -r requirements.txt pyinstaller
.\build.ps1          # dist\MultiSpeaker\ 与 dist\MultiSpeaker-Portable.exe
```

安装包需要 Inno Setup 6 与简体中文语言文件，详见 `installer/README.md`。

## 9. 建议阅读顺序

1. `app/devices.py` → 认识端点模型
2. `app/decode.py` → 音频如何变成数组
3. `app/chmap.py` → 声道矩阵规则
4. `app/engine.py` → 同步核心（`_DeviceWorker.callback` 与 `MultiSpeakerEngine`）
5. `app/live.py` → 实时采集通路
6. `app/ui/main_window.py` → 界面如何驱动引擎
