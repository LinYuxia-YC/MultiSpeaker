# MultiSpeaker 使用说明

> 版本 1.0.0 · Windows 10 / 11 64 位

MultiSpeaker 把同一个立体声音频同时送到电脑上的任意多个扬声器、声卡、HDMI 或蓝牙设备，
每台设备都保留完整的**左 (L) / 右 (R)** 声道，不会混成单声道；所有设备由同一个主时钟对齐。

![主界面](images/ui.png)

---

## 1. 快速上手

1. 左侧「输出设备」勾选要同时发声的扬声器（可多选）。
2. 点右上角「选择文件」，或把音频文件 / 文件夹直接拖进窗口。
3. 点播放（或按空格键），所有勾选的设备会同时开始。
4. 点「声道测试」——会依次播放 左声道 → 右声道 → 双声道，用来确认每台设备都是真正的立体声。

> 播放过程中勾选 / 取消设备会立即生效，无需停止播放。

## 2. 每台设备的控制

| 控件 | 作用 |
|---|---|
| 音量滑杆 | 只调节这一台设备的音量 |
| **M** | 静音这台设备 |
| **S** | 独奏：只听这一台（用来分辨哪个音箱对应列表里的哪个设备） |
| 延迟补偿（−300…+300 ms） | 正值 = 这台设备相对其他设备**更晚**出声，用于对齐蓝牙音箱等本身延迟较大的设备 |
| L / R 电平表 | 实时显示该设备左右声道电平，可直观确认没有下混成单声道 |

### 立体声 / 单声道切换

播放器标题下方的「立体声」标签可以点击切换：

- **立体声（默认）**：左、右声道独立传输，保留声场
- **单声道**：L + R 取平均后送到所有声道（多声道设备也会铺满）

也可以在「设置 → 输出声道」里修改。默认关闭——只有全场播放同一内容，
或单声道素材被错误地只送到一侧时才建议开启。

## 3. 播放列表与格式

- 支持多选添加、拖放文件夹（自动递归）、双击播放、上一首 / 下一首、单曲循环、拖动波形跳转
- 支持 MP3 / FLAC / WAV / M4A(AAC) / OGG / OPUS / WMA / AIFF / APE / MP4 / MKV
- 44.1 kHz、48 kHz、96 kHz 等任意采样率都会自动转换到设备采样率（soxr HQ）
- 快捷键：`空格` 播放/暂停、`Ctrl+O` 打开文件、`←` / `→` 后退/前进 5 秒、`Esc` 停止

## 4. 系统音频（让所有程序的声音都走组合输出）

Windows 不允许普通应用创建音频端点，所以需要一个签名虚拟声卡（推荐官方免费的 VB-CABLE）。

1. 安装 VB-CABLE 后，Windows「播放设备」里会出现
   `CABLE Input (VB-Audio Virtual Cable)`。
2. 把它改名为 **`MultiSpeaker 组合输出`**（可选，便于识别）：
   见下方「重命名播放设备」。
3. Windows 设置 → 系统 → 声音 → 输出：选择「MultiSpeaker 组合输出」。
4. 回到 MultiSpeaker，勾选要同时发声的扬声器，
   点顶部「系统音频」卡片的 **开始转发**。

此后浏览器、音乐软件、游戏等所有程序的声音都会同步出现在这些扬声器上。

- 停止：点「停止转发」，并把 Windows 默认输出切回原来的设备
- 转发链路有约 80 ms 缓冲（端到端约 100 ms）；看视频时如需唇音同步，请在播放器里做音频延迟补偿
- 软件会自动排除虚拟声卡自身的播放端，避免把转发结果再次喂回自己

![系统音频](images/system-audio.png)

### 重命名播放设备（可选）

Windows 10 的「声音」设置没有重命名入口。可以：

- 使用第三方小工具（如 SoundVolumeView）修改端点名称；或
- 在注册表 `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\MMDevices\Audio\Render\{端点GUID}\Properties`
  中把 `{a45c254e-df1c-4efd-8020-67d146a850e0},2` 改为想要的名称，然后重启音频服务。

> 名称只是显示用，不影响功能。

## 5. 启动与托盘

右上角「设置」里：

- **开机自动启动**：登录 Windows 后静默驻留托盘，不弹窗（写入当前用户的 Run 键，不需要管理员）
- **关闭窗口时**：
  - 最小化到托盘（音乐继续播放，默认）
  - 直接退出程序

托盘图标：

- **单击**：打开主界面
- **右键**：「打开主界面」/「退出 MultiSpeaker」

![设置](images/settings.png)

> Windows 10 的新托盘图标可能被收进「隐藏的图标」小箭头里，把它拖到任务栏即可常显。

## 6. 多声道设备（5.1 / 7.1）

默认把 L / R 分配到前置、后置各一对扬声器，中置取 (L+R)/2、低音静音。
可在「设置 → 多声道设备分配」改为**仅前置声道**。

## 7. 常见问题

**Q：某台设备没有声音？**
- 确认系统音量 / 设备静音（卡片上的 M）与实体音量
- 有些 HDMI / 蓝牙设备在空闲时会被系统挂起，重新插拔或点一次「刷新设备」

**Q：两台设备听起来有先后差？**
- 蓝牙设备通常有 100 ms 以上延迟。用「延迟补偿」给**另一台**设备加正值，或给蓝牙设备加负值（使其提前）

**Q：系统音频模式没有声音？**
- 确认 Windows 默认输出已切到「MultiSpeaker 组合输出」
- 点「系统音频」卡片确认已显示输入设备与电平

**Q：能同时播放不同的歌到不同设备吗？**
- 目前是「同一份立体声到多台设备」，不支持多路独立混音

## 8. 卸载

开始菜单 → MultiSpeaker → 卸载 MultiSpeaker，
或：Windows 设置 → 应用 → 已安装的应用 → MultiSpeaker → 卸载。

卸载会同时删除开机启动项与用户设置，不会删除你的音频文件。
